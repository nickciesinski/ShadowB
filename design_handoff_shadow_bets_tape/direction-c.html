Direction C
Run — build as a sequence
The morning session is treated as a task with a beginning and an end. Build mode is a guided run through the leagues one at a time, with a progress stepper at the top and a commit footer that fills as you go — the app tells you when you are finished. Watch mode is not the same screen dressed differently; it is a separate ranked feed with no game grouping at all, ordered by which position is closest to being decided.

Type
Display & body Manrope 700/800 at −0.035em for screen titles. Numeric DM Mono 500 — lighter than the sans, so numbers read as data rather than headlines.
Layout
18px gutters, soft 13–14px panels on near-black. One screen = one league. Chrome is minimal at the top and heavy at the bottom, where the thumb is.
Signature
The commit footer. Always present in build mode: running count, units, a fill bar across the whole slate, and one forward action that turns into Lock slate on the last league.

Optimizes for

Finishing. The user goes league by league already, so the app makes that the structure and gives it an end state — the fill bar and the Lock leg mean you know the slate is done without auditing it. Watch mode removes the reading work entirely: the position closest to being decided is at the top, with the number that decides it spelled out in words.

Gives up

Free browsing. A sequence resists jumping around, so "just show me the Mets game" needs an escape hatch (search, or the Scores tab). And because watch mode drops game grouping, two positions on the same game can sit far apart in the feed.

Desktop

The legs become a left rail listing all leagues with counts, so the sequence stays visible but becomes non-linear. The commit footer docks bottom-right as a persistent tray. Watch mode goes two-column: ranked feed left, selected game detail right.

Logos

24px circular marks; the smallest of the three directions, so it needs clean single-color-safe crops. If assets are inconsistent across leagues, this is the direction that suffers most — consider bumping to 28px.
