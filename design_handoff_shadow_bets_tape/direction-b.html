Direction B
Block — spacious, one card per game
Warm charcoal, heavy display type, generous 46px targets. A game is a physical object you hold; its markets stack inside it. Taking a position is a two-button decision — Take or Fade — because "model, untouched" is the absence of a choice, not a third button. Build and Watch are an explicit switch in the header, so the app never changes character underneath you.

Layout
16px gutters, 16px card radius, one card per game, markets as internal rows. Nothing is full-bleed; the background always shows through so cards feel liftable.
Signature
The rule sheet. Tier blocks plus a unit-floor slider in a bottom sheet, with a live consequence readout that names the count and units before you commit.

Optimizes for

Confidence and thumb comfort. 46px Take/Fade targets are impossible to mis-hit, the fade state gets its own hue and a plain-English line naming what's being faded, and the exposure block at the top is legible from across a room. Watch mode is genuinely three-second scannable.

Gives up

Density. Roughly two games per screen instead of four, so a 45-play slate is a lot of scrolling — the rule sheet has to carry more weight because working row by row through this layout would be slow. Cards also make it harder to compare unit sizes across games at a glance.

Desktop

Cards become a two- or three-column masonry at the same 390px intrinsic width, so nothing restyles. The rule sheet un-sheets into a right sidebar that stays open while you refine, and the exposure block spans the top as a full-width bar.

Logos

30px rounded chips carry real marks comfortably. Team color already does the identification work here, so if an asset is missing the monogram is a genuine fallback rather than a placeholder.
